# 生图文件类型图标

由内置 image_gen 在 2026-11-04 生成，`generation.json` 保留完整提示词与源输出位置。`source` 是保留的原图，`runtime` 是 OpenPencil 按可见 alpha 边界裁去透明留白后等比导出的 192 px PNG，保留透明度，供程序内置加载。没有将代码绘制的 SVG 冒充生图输出。

15 张图案：文件夹、Word、表格、演示、PDF、默认应用、安装包、图片、视频、音乐、归档、电子书、字体、代码、通用文档。源码、标记和配置的语义分类共享代码图案。EXE 读取到自己的内嵌图标后优先显示原图标。

可编辑设计容器与小尺寸/明暗/状态检查在 `design/Backleaf-v15.fig`。重建：`bun scripts/design/file-icons-v15.mjs`；冷重开：同命令加 `--verify`；更新原生绑定：`bun scripts/design/export-file-icons.mjs`，检查时加 `--check`。

2026-11-04 追加改稿：文件夹使用新生成的圆润、低描边图案，并同步到左侧 18 px 导航。透明输出在导出阶段保留主轮廓、清理淡白/青色游离像素和微小 alpha 缺口，重新生成平滑抗锯齿；原图及代码图标的修边候选均保留，不覆盖原始生成历史。
