# SIM-1003 · 原位刷新

外部或应用内文件增删改不应触发一次目录导航。后台准备下一份磁盘快照期间，继续显示当前文件、标签、选区和详情，沿用滚动句柄与键盘焦点。没有空列表过渡、遮罩或整页位移动画。

下一份枚举完整、身份映射和可见页就绪后，在一帧内提交。文件身份与原始名称同时匹配；重命名仅在身份唯一时保留选区。删除及同名替换不能继承选择。大量选择在后台使用压缩位图映射，不在UI线程遍历所有文件。可见页与标签缓存保持有界。

后台读取失败保留旧视图并使用既有短错误toast。路径导航取消待提交快照，迟到结果不能覆盖新目录。读取期间发生的新变更保留为下一轮失效；滚动、选区、列数变化后重新准备对应页再提交，不把过时交互状态写回。

同一搜索条件的自动刷新也保留现有结果，直到新一代对应可见页就绪；搜索条件主动变更仍取消旧一代。保留结果不等于跨查询结果缓存，后者仍未实现。

OpenPencil v40新增238–241页：原画面、后台准备、原位提交、失败保留。前三页稳定布局相同，错误只增加短浮层。最终无头检查必须覆盖刷新中不清空、选区身份、滚动句柄、错误保留与导航取消。

大选区采用一次有索引的SQLite关联处理精确身份与原名匹配，仅稀疏例外走逐条歧义检查。10万项逆序快照测试的映射从51.944秒降为166.299毫秒，输出96项可见页和37字节选区位图；这是本机合成数据库检查，不包含真实目录枚举、GPU或磁盘端到端耗时。
