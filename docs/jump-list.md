# 任务栏跳转列表

2026-11-09。说明 Backleaf 在 Windows 任务栏按钮右键菜单（Jump List）里提供的入口、数据来源、刷新方式与已知边界。

## 布局

参考资源管理器但**不记录最近访问**；每个条目都通过 `Backleaf.exe` 的新进程打开，不会打开资源管理器：

| 分组 | 内容 | 上限 |
| --- | --- | --- |
| 固定 | 侧栏中用户固定的文件夹入口（`folder-*`），保留侧栏顺序 | 10 |
| 视图 | 侧栏中保存的视图入口（`view-*`），保留侧栏顺序 | 10 |
| 常用 | 当前用户家目录 + 桌面、下载、文档、图片、音乐、视频 | 8 |
| 分区 | 当前挂载的逻辑磁盘（`C:\`、`D:\` 等） | 8 |
| 任务 | 打开新窗口（主文件夹） | 1 |

- 「固定」只包含用户自己固定的文件夹；系统初始的常用目录归入「常用」，避免重复。
- 「常用」是固定列表，不随访问频率变化，也没有「最近」语义。
- 单击条目启动 `Backleaf.exe --path "<文件夹>"`、`--view <视图 id>` 或 `--new-window`，每个入口打开独立的新窗口；已有窗口不变。
- 任务「打开新窗口」等价于 `--new-window`：跳过窗口恢复，打开主文件夹的新窗口。

## 数据来源与刷新

- 侧栏入口：只读打开 `%LOCALAPPDATA%\Backleaf\operations\quick-access.sqlite`，按 `position` 读取；WAL 读连接不会阻塞 UI 写连接。
- 常用目录：`SHGetKnownFolderPath`（家目录标题使用实际文件夹名，与侧栏一致）。
- 分区：`GetLogicalDrives` + `GetDriveTypeW`，标题如「本地磁盘 (C:)」。
- 刷新触发：应用启动、快捷访问 revision 变化、磁盘快照变化、`Ctrl+Shift+L` 切换语言。多次触发会合并为一个后台刷新，不阻塞 UI；构建或写入失败只记日志，不影响应用运行。
- 用户在系统跳转列表里移除的项会按启动参数过滤；下次刷新按当前侧栏数据重新生成。

## AppUserModelID 与快捷方式

- 进程、跳转列表和快捷方式使用固定 AppUserModelID：`Simiooo.Backleaf`。启动时调用 `SetCurrentProcessExplicitAppUserModelID`。
- 旧版本创建的「开始菜单」和「任务栏固定」快捷方式没有该 ID；应用启动时会把已存在的 `Backleaf.lnk` 就地补上 `System.AppUserModel.ID`（属性存储写回，失败只记日志）。
- 升级后第一次启动会在窗口创建前修复快捷方式，使已固定的任务栏按钮与新进程合并且出现跳转列表。若系统仍显示旧行为，取消固定再固定一次即可。

## 已知边界

- 只有 Windows 任务栏跳转列表；不接管 Win+E、默认文件管理器或资源管理器导航。
- 不记录最近访问；没有「最近」或自动常用。
- 不支持用户自定义命名的跳转列表分组；分组与顺序由侧栏数据决定。
- 仅当前存在的文件夹/磁盘/视图会出现在列表；失效路径仍按侧栏数据生成，点击后由应用显示真实错误。
- 每个分组有数量上限（见上表）；超出部分不会出现。
- 便携版直接运行同样具备运行中/固定按钮的跳转列表；标准快捷方式修复只覆盖开始菜单与任务栏固定路径。

## 验证

- 单元测试覆盖：启动参数的无损 UTF-16 引用、固定/视图分类、保存视图窗口状态；无头回归门禁不变。
- 诊断：设置 `BACKLEAF_JUMP_LIST_DUMP=<json 路径>` 后启动应用，会把当前跳转列表模型（标题、目标、参数）写入该文件，便于打包证据与问题定位。
- 人工验收：安装/运行后右键任务栏按钮，应看到「固定 / 视图 / 常用 / 分区 / 任务」；点击各条目应分别打开对应 Backleaf 窗口；「打开新窗口」打开主文件夹窗口。
- CI 不模拟任务栏 UI；跳转列表写入的系统 `CustomDestinations` 文件和 AUMID 快捷方式属性可在实机检查。
