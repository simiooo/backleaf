# 窗口栏搜索入口与本地名称搜索

用户试包指出搜索入口缺失。v12 在窗口栏右侧、窗口控制按钮前常驻放大镜与「搜索」，提供 Ctrl+F；窄窗保留图标及 tooltip。保留现有面包屑、路径编辑与左侧唯一快捷访问。

搜索范围固定为打开入口时的当前目录，包含子目录。输入 250 ms 后执行，Enter 立即执行；中文输入法预编辑期间不检索或提交。Esc / 点击外部取消并收起；点击结果或上下方向键选择后 Enter，在原目录定位选中文件。名称与位置分别单行省略，tooltip 与无障碍名称提供完整路径。搜索不执行文件操作。

一个最新请求优先的后台线程，SQLite 保存待遍历目录与结果，UI 只加载最多 32 行，不积累整个目录树或结果数组。逐批 256 项扫描，每 100 ms 最多通知一次进度；旧查询、关闭与导航使令牌失效。不展开子目录中的链接 / reparse point，避免越出范围或循环；显式打开的根目录可为 Known Folder 重定向。无法访问和未展开链接数量可见，不把不完整结果表述为完整覆盖。

字面文件名子串匹配，大小写不敏感，支持中文单字；百分号、下划线和方括号按普通文字处理。匹配不读文件正文、不联网。此次 SQLite 是临时结果存储，不宣称已完成 SIM-922 的持久全局索引。类型/日期等筛选、保存搜索与统一快捷访问的动态规则、启动恢复仍继续原事项。

OpenPencil [v12 可编辑稿](../design/Backleaf-v12.fig) 保留 84 页并新增 8 页：入口、输入、扫描中、结果、无结果、覆盖不足、窄窗和深色。冷重开 92 页，新增页逐像素比较通过。

Windows 本机 CLI 对同一只读 worker 的一次暖缓存样本：真实 100,001 项目录，`.txt` 匹配 100,000 项，首批通知约 240 ms，扫描完成约 1.16 秒；中文「文件」匹配 991 项，约 196 ms。两次首尾分页最多 32 行，结果均存在。独立 junction 夹具未进入目标目录，记录 1 个未展开链接。数值仅为本机该样本，不是跨硬件结论或 GPU 帧率。
