本批次（新增拖放/删除刷新修复，含失败项重试与剪贴板互操作验证及 preview.26 既有内容）：
- 删除等应用内操作完成后立即刷新目录；快照提交前已移除项保留淡化占位，不再出现整行空白。
- 目录刷新期间仍接受外部OLE拖放，删除文件后立即再次从 Explorer 拖入可正常接收；目标仍按捕获身份校验。
- 失败任务重试：任务结束且存在确认失败项时显示“重试”；只重放已确认失败的顶层项，成功、未确认、取消及部分完成目录不重放，同一任务只重试一次；真实窗口以锁定文件部分失败后释放再重试验证，目标无重复、源完整。
- Explorer 文件剪贴板互操作实机通过：Backleaf 复制/剪切到 Explorer 粘贴、Explorer 复制到 Backleaf 粘贴均按真实文件内容验证；外部剪贴板变化会清除剪切标记。
- 独立详情窗口展示完整名称/路径、大小与时间；文件夹后台统计并节流更新数字，F5刷新、Esc/Ctrl+W关闭取消，不挤占主文件区。
- 搜索结果两行文字更紧凑、整体垂直居中并上下留白，hover与选中不改变排版。
- 右键新建后保留命名焦点；短成功操作不弹常驻面板，长任务紧凑进度与取消、失败按需查看。
- 搜索结果缓存：普通路径随递归通知失效，索引结果按变更ID更新；完整查询键、8查询/128MiB/60秒、可见页验证与安全回退。
- 容量副文案10px，一体静态用量条；B/KB/MB/GB自动单位、去除多余.0并处理临界舍入。
- 圆叶小表情应用logo和九档透明Windows图标；附独立三页OpenPencil品牌稿。
- 文件变化后台准备后原位提交，保留滚动与身份可验证的选择；失败保留旧列表。
- 分区总量/剩余/使用率、卷接口PnP通知和独立后台容量探测。
- 选择浮层增加文件大小；文件夹不递归，未知数据不填0。
- 重复单字母循环定位，输入框及多字母前缀保持正常。
- 40项GPUI无头与112项逻辑/文件/原生检查，OpenPencil v46/271页。

保留路径/分区导航、统一快捷访问和FileView、持久化增量索引、文件操作进度、ZIP创建和ZIP/7z/RAR提取、恢复、多窗口、独立自绘Shell菜单、OLE拖放、虚拟网格/长文本/流光与框选加速。已补齐跨查询结果缓存，普通路径按通知失效，索引搜索按事务变更ID更新；8查询/128MiB/60秒，重启安全丢弃结果缓存。
