拾径 / Backleaf 0.1.0-preview.15

Windows x64 便携测试版：解压整个 ZIP，运行 Backleaf.exe。

本批次加入：
- 16项GPUI无头交互回归与GitHub CI门禁；包内headless.json提供用例和日志摘要。
- 同名重命名直接提示错误、保留草稿并恢复焦点，不覆盖已有文件；大小写重命名继续支持。
- 分级路径右键菜单、手动路径编辑、真实磁盘入口。
- 非输入状态下键入名称定位，外部文件变更自动合并。
- 目录内拖动移动、物理目录环检测；文件夹固定到侧栏，导航入口重排。
- 搜索筛选、排序、分组、列表/网格，保存为同一侧栏中的 FileView。
- 本地持久元数据索引、中文短查询、索引位置管理。
- 创建 ZIP；提取 ZIP、7z、RAR；逐项/字节进度、取消与冲突处理。
- 第三方扩展项由 Backleaf 自绘；右键菜单为独立owned浮窗，隔离宿主只发现和执行命令。
- 正常/异常退出后的路径和搜索意图恢复；Ctrl+N 独立窗口。
- 文件主区圆角16与极轻浮层层级，保留已有长文本、虚拟渲染与框选加速。

常用操作：
Ctrl+F 搜索；Ctrl+L / Alt+D 编辑路径；Ctrl+N 新窗口。
Ctrl/Shift 多选，Ctrl+A 全选；空白处拖动框选，Esc 取消当前交互。
Enter 打开；Alt+Enter 详情；右键 / Shift+F10 菜单。
F2 重命名；Ctrl+C/X/V 复制/剪切/粘贴；Ctrl+Shift+C 复制路径。
Delete 移至回收站；Ctrl+Shift+N 新建文件夹；F5 刷新。
输入失焦会提交；错误保留草稿并恢复编辑。输入法组合期间需先确认候选。

测试范围与界限：
本版81项逻辑/文件/COM协议测试与16项GPUI无头交互测试分别门禁（合计97项），记录见docs/evidence/preview-15。无头运行生产视图和隔离文件工作线程，通过实际事件分发检查输入、失焦、错误恢复、搜索、菜单焦点和框选滚动。文字是合成度量、无GPU像素或屏幕阅读器适配，不冒充系统IME/Explorer拖放或性能验证。原生COM协议覆盖同步/异步接收、真实移动和避免二次删除；preview.14的具体第三方命令与性能实测仍保留。
窗口工具不允许拖动终点越过源窗口，跨窗口/Explorer手势未自动计为实机通过，需产品验证。混合DPI/NVDA/长期压力也尚未验证。CI执行源码、隔离文件操作、原生COM协议与打包CLI冒烟。
此前preview.13搜索、失焦保存/错误恢复、导航、外部变更、归档、恢复、多窗与海量GPUI实测保留在docs/evidence/preview-13，不冒充本版EXE证据。
原生OLE支持跨窗口及外部真实文件的CF_HDROP拖放。Ctrl复制/Shift移动，默认按卷关系；侧栏一次固定一个文件夹。虚拟文件内容与创建链接尚不支持；路径总预算256MiB，超限整次拒绝，不截断。外部目标负责实际移动，Backleaf不凭效果通知自行删除源文件。
索引只记录名称/路径/大小/时间，不上传内容；不跟随子目录链接或云占位目录。首次建立索引期间结果尚不完整。
归档不支持密码、分卷、链接/特殊条目；资源上限100万项、1TiB。解压到新目录，不覆盖已有目标。
第三方扩展兼容传统IContextMenu接口；动态子菜单保留禁用/勾选/单选语义，无法提取菜单文字的owner-draw项不可用。不保证全部Windows11现代扩展；选区上限2048项/512KiB，不截断选择。
恢复只重新执行查询，不自动重放文件操作。归档提交中断后核对结果身份；其他中断操作不推测回滚成功。

包内：EXE、Logo、233页可编辑 OpenPencil v38设计、build.json、许可证及7-Zip对应完整源包。
7-Zip 动态库位于 lib/7z.dll，可替换兼容的x64修改版；详见 licenses/7-Zip-26.05。
