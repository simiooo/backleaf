拾径 / Backleaf 0.1.0-preview.13

Windows x64 便携测试版：解压整个 ZIP，运行 Backleaf.exe。

本批次加入：
- 分级路径右键菜单、手动路径编辑、真实磁盘入口。
- 非输入状态下键入名称定位，外部文件变更自动合并。
- 目录内拖动移动、物理目录环检测；文件夹固定到侧栏，导航入口重排。
- 搜索筛选、排序、分组、列表/网格，保存为同一侧栏中的 FileView。
- 本地持久元数据索引、中文短查询、索引位置管理。
- 创建 ZIP；提取 ZIP、7z、RAR；逐项/字节进度、取消与冲突处理。
- “其他应用操作”打开独立进程承载的原生 Shell 菜单。
- 正常/异常退出后的路径和搜索意图恢复；Ctrl+N 独立窗口。
- 文件主区圆角16与极轻浮层层级，保留已有长文本、虚拟渲染与框选加速。

常用操作：
Ctrl+F 搜索；Ctrl+L / Alt+D 编辑路径；Ctrl+N 新窗口。
Ctrl/Shift 多选，Ctrl+A 全选；空白处拖动框选，Esc 取消当前交互。
Enter 打开；Alt+Enter 详情；右键 / Shift+F10 菜单。
F2 重命名；Ctrl+C/X/V 复制/剪切/粘贴；Ctrl+Shift+C 复制路径。
Delete 移至回收站；Ctrl+Shift+N 新建文件夹；F5 刷新。
输入失焦会提交；错误保留草稿并恢复编辑。输入法组合期间需先确认候选。

测试范围与界限：
本机 Release 测试及严格静态检查记录见仓库 docs/evidence/remaining-batch。
本机已实测中文搜索、失焦保存/错误恢复、路径导航、拖动移动/固定/重排、外部变更与跨窗口剪切粘贴。修复版焦点/系统菜单与海量性能复测仍在进行；混合DPI/NVDA尚未验证。CI执行源码、隔离文件操作与打包CLI冒烟。
文件拖放目前限同一窗口；快捷访问一次固定一个文件夹。暂不支持跨窗口/外部OLE拖放。
索引只记录名称/路径/大小/时间，不上传内容；不跟随子目录链接或云占位目录。首次建立索引期间结果尚不完整。
归档不支持密码、分卷、链接/特殊条目；资源上限100万项、1TiB。解压到新目录，不覆盖已有目标。
第三方扩展通过兼容原生菜单承载，不保证全部Windows11现代扩展；选区上限2048项/512KiB，不截断选择。
恢复只重新执行查询，不自动重放文件操作。归档提交中断后核对结果身份；其他中断操作不推测回滚成功。

包内：EXE、Logo、219页可编辑 OpenPencil v35设计、build.json、许可证及7-Zip对应完整源包。
7-Zip 动态库位于 lib/7z.dll，可替换兼容的x64修改版；详见 licenses/7-Zip-26.05。
