拾径 / Backleaf 0.1.0-preview.8

拾径 / Backleaf Windows x64 便携测试版。解压 ZIP，运行 `Backleaf.exe`。

本次加入左侧常用目录导航；顶部面包屑参考 Ant Design 与 shadcn，支持祖先链接、折叠菜单、当前位置下拉、箭头点击展开和双击当前位置编辑，保留 Ctrl+L / Alt+D。文件及空白处右键打开上下文菜单，详情由菜单或 Alt+Enter 显式打开。选中计数改为内容宽度的悬浮盒，不再占用底部一整行。新 Logo 继续嵌入 EXE 与窗口。

文件操作处于验证阶段，本次新增标题栏右侧搜索入口（Ctrl+F），默认搜索当前目录及子目录的文件名。本次适合在测试目录中试用；保存搜索分组、全局索引与启动恢复仍在研发。本地已检查搜索入口、中文递归名称搜索、结果定位、导航、路径输入、菜单与新建流程，CI 执行格式、Clippy、行为测试、Release 构建及解压后 EXE 的 CLI 冒烟；不把托管 CI 当作可见桌面验收。

可编辑 OpenPencil v19 共 137 页，随 ZIP 提供，也可单独下载。具体源码与 CI 入口见 `build.json`，文件校验值见 `SHA256SUMS.txt`。


Ctrl/Shift 多选，Ctrl+A 全选，空白处拖动框选，Esc 撤回或关闭临时界面。
右键与 Shift+F10 打开菜单。Enter 打开、Alt+Enter 详情。
F2 重命名；Ctrl+C/X/V 复制/剪切/粘贴；Ctrl+Shift+C 复制路径；Delete/Ctrl+D 移至回收站；Ctrl+Shift+N 新建；F5 刷新。
路径祖先单击导航，双击当前目录编辑；Ctrl+L/Alt+D 编辑。

渲染样本：Backleaf.exe --fixture 1000000 --flow 8，样本不执行文件命令。

本版修复真实键盘搜索输入；重命名支持失焦保存并接续目标右键菜单；选择文件名保持常规字重，完整名称 tooltip 只由文件名区域触发。输入框以表面与阴影表达激活层级。

输入法候选未确认就离开重命名时，若系统撤回组合文字，本版会保留输入并提示先确认候选；不会提交被截断的名称。Enter/Esc 在搜索中优先交给正在组合的输入法。

新增生图文件类型图标：Office三件套、PDF、图片、视频、音乐、归档、安装包、电子书、字体和源码；源码统一使用代码符号，保留文件扩展名。EXE优先后台读取内嵌应用图标，失败保留默认应用图标。图标显示不表示文件内容已校验或可运行。

窗口栏搜索默认仅显示图标，点击展开；Esc、点击内容区或进入路径编辑时缓出收起，支持中途反向与减少动态效果。窗口栏上下留白8px、按钮间隔8px；hover/focus采用轻阴影。

侧栏移除可见的快捷访问标题；Tab焦点采用中性轻浮层，当前目录选中状态独立保留。外部软件CRUD自动同步暂未实现，当前用F5刷新。

本次将已选项浮层缩为28px高；文件区按完整目录范围计算比例滚动条，左侧仅指针移入且内容溢出时显示，修复子滚动条遮挡造成的显隐闪烁。支持拖动、轨道分页、键盘及辅助技术数值动作；列布局保留固定滚动条空间。外部CRUD同步和字母键定位仍在独立研发单元，当前不宣称支持。
