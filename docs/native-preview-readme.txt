拾径 / Backleaf 0.1.0-preview.11

Windows x64便携测试版：解压ZIP，运行Backleaf.exe。

本版：海量框选渐进提速。浅边缘精调；深边缘持续停留后平滑加速，速度随完整目录范围适配。返回内容区立即停止，反向从低速开始，滚轮重置加速。松开后等待最终选区稳定，再允许文件操作。

Ctrl/Shift多选，Ctrl+A全选，空白处拖动框选，Esc撤回正在进行的框选。
Enter打开，Alt+Enter详情；右键/Shift+F10打开上下文菜单。
F2重命名；Ctrl+C/X/V复制/剪切/粘贴；Ctrl+Shift+C复制路径；Delete移至回收站；Ctrl+Shift+N新建文件夹；F5刷新。
路径祖先单击导航，双击当前目录或Ctrl+L/Alt+D编辑路径。Ctrl+F展开当前目录及子目录的文件名搜索。

包内包含Logo、许可证、149页可编辑OpenPencil v22设计；实际源码/版本见build.json，校验值见SHA256SUMS.txt。

实机持续滚动使用合成控制器驱动同一个真实GPUI窗口，另有真实鼠标基础拖框冒烟；详情与边界见仓库docs/evidence/marquee-acceleration。

已有能力包括虚拟文件网格、长文件名省略/文件名tooltip/完整详情、原生EXE图标与文件类型图标、可伸缩搜索、比例滚动条和简洁选中态。文件操作仍在验证阶段，建议先用测试目录。

尚未交付：路径分级右键/磁盘入口候选、字母定位、文件移动拖放、压缩解压、第三方Shell菜单、外部CRUD自动同步、保存搜索/全局索引/启动恢复。

输入法候选未确认就离开重命名时，若系统撤回组合文字，会保留输入并提示先确认候选；Enter/Esc优先交给正在组合的输入法。
