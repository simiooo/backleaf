本批次（中文 / English 界面）：
- 启动时按 Windows 界面语言选择中文或 English；也可按 `Ctrl+Shift+L` 切换，选择写入状态目录 `language.txt`，下次启动沿用；`BACKLEAF_LANG=en/zh` 可显式覆盖。
- 已翻译主窗口、右键菜单、搜索与内容搜索、筛选/字段错误、文件操作与任务面板、详情窗口、侧栏位置、拖放/归档/恢复提示及常见错误；不支持的字符串回退中文而不是空白。
- 翻译采用源字符串 + 紧凑词典，保留格式占位符（`{}`）与复数无关的简洁文案；语言切换即时生效，无需重启。
- 新增 i18n 单元测试与 headless `language_shortcut_switches_chinese_and_english`；headless 现为 51 项、native 133 项。
- 首次覆盖以高频界面为主，少数深层/第三方 Shell 错误可能仍是中文；Shell 扩展自身的菜单文字由 Windows/第三方软件提供，不受本应用语言控制。

以下保留 preview.41 及更早内容：

preview.41（内容搜索 / grep 式文本搜索）：
- 搜索框工具栏新增“内容”模式：从当前搜索位置递归检查文件内容，不再只匹配文件名；普通文件名搜索仍默认保留。
- 文本类型按内容嗅探而非后缀：接受 UTF-8、UTF-8 BOM、UTF-16 BOM，拒绝含 NUL、控制字符比例异常或非法 UTF-8 的文件；边界为单文件 8MB、20,000 文件、8,000 目录、累计 256MB、最多 200 个结果，超出显示“结果已截断”。
- 结果为响应式卡片网格：占据内容区大部分空间，按宽度自动 1–N 列；卡片无边框/分割线，用文件图标、名称字重、路径/行号次级文字和间距组织。卡片主体是匹配上下文块（前后各一行），所有匹配文本用浅色块高亮；点击卡片或 Enter 定位到文件。
- 匹配为 ASCII 大小写不敏感；不支持正则、全词匹配和 GBK/旧编码（非 UTF-8/BOM 文本会被判定为非文本）。
- 内容模式暂不支持筛选/保存视图，也不做逐次增量索引；每次查询重新扫描，受上述上限保护。

以下保留 preview.40 及更早内容：

preview.40（Shell 异步次级菜单空状态）：
- 修复 Shell 扩展次级菜单异步返回空列表时弹出空白面板的问题：现在显示一行禁用的“没有可用的菜单项”，保持正常菜单行高，不再出现空白半截面板。
- 次级菜单仍等待异步行返回后才创建弹窗，避免加载占位窗口反复调整大小；查询失败显示“扩展暂不可用”。

preview.39（高级搜索容量单位与字段级错误）：
- 最小/最大容量支持宽容输入：`10MB`、`500 KB`、`1.5GB`、`2g`、`1024`、`3 字节` 等，按 B/KB/MB/GB/TB 二进制换算；未识别单位、负数、溢出会拒绝。
- 非法输入在对应输入框显示红色边框，并在框下显示红字错误；自动聚焦第一个错误字段，编辑时清除红框，下一次提交重新校验。
- 类型字段支持逗号/中文逗号/分号/空格分隔与开头的点；最近天数支持 `7`、`7天`、`7日`，范围 1–365000；最小容量不能大于最大容量。空字段清除对应筛选。
- 表单预填容量显示为友好单位（如 `10 MB`）；新增字段占位提示。

以下保留 preview.38 及更早内容：

preview.38（焦点切换不重解码图片）：
- 最小化/失焦/重新聚焦不再无条件标记目录刷新；只有 watcher 确实报告内容变化（watch_stale）时才刷新，避免焦点切换引发整目录刷新。
- 缩略图缓存失效改用“已应用的监听内容 epoch”（watch.applied），不再用每次记账刷新都会递增的 generation；内容未变的目录刷新保留已解码预览，不重新解码、不重新请求。
- 仍只为当前可见行请求缩略图；新增 headless 回归 `image_preview_cache_survives_unchanged_directory_refresh`。

preview.37（图片预览选中溢出与重绘修复）：
- 选中/悬停底板现在按缩略图尺寸计算（新增 `surface_with_art`），图片不再超出蓝色选中容器；名称/提示命中区域同步使用预览高度。
- 缩略图解码结果每 20ms 合并为一次窗口通知，避免每个缩略图触发一次整窗重渲染；已解码图片在滚动/选中时复用缓存。

preview.36（可视区内图片缩略图）：
- 图片文件（png/jpg/jpeg/gif/webp/bmp/tif/tiff/ico）用实际内容替换类型图标；容器为单元格内宽 × 48px，按比例 contain 居中，最大化占用且不溢出；缩略图未就绪时先显示原类型图标。
- HEIC/AVIF/视频暂不解码；大于 64MB 或解码失败的文件回退图标；GIF/WebP 只显示首帧；JPEG 应用 EXIF 方向。
- 搜索结果中的图片也使用缩略图；新增无头回归 `visible_image_cells_decode_thumbnails_lazily`。

preview.35（无任务时不显示任务入口/结果面板）：
- 文件操作完成且没有可安全重试的失败项时，不再常驻标题栏“任务”入口和右下角结果面板；可重试失败仍保留面板与重试按钮。

preview.34（高级搜索不再触发空查询扫描）：
- 打开/编辑高级搜索时要求文本查询非空；空查询不再启动整树扫描，Worker 也只返回 0 项完成事件；关闭搜索清理筛选状态。

preview.33（路径面包屑响应式展开）：
- 路径面包屑不再固定 600px 或固定四段；按标题栏实际剩余宽度动态计算，宽度越大显示越多祖先，只有中间放不下才出现省略号；当前目录始终保留（可截断），窗口缩放立即重排。

preview.32（框选边缘自动滚动加速）：
- 720px 视口下满深度起步约 1.8 屏/秒（约1300px/s），浅深度（0.2）约0.31屏/秒；持续贴边约0.7秒后加速到约5.3屏/秒，长列表穿越目标约8秒；返回/反向立即回到精细档，松手无惯性。

preview.31（搜索空输入修复）：
- 空查询不再保留搜索浮层：Ctrl+F 打开搜索时，空输入只保留输入框，不显示结果/工具栏弹层；输入过查询后清空会退出搜索并恢复文件区焦点；点击弹层外区域可关闭空搜索。

preview.30（索引与搜索加速，保留）：
- 持久索引维护：批量目录枚举、keyed 目录 diff、通知批事务与改名配对；2 万文件树全量构建约 17s、无变化启动重扫约 1.2s（优化前约 23s / 25s）。
- 智能调度：系统空闲时全速索引，有用户输入时自动限速；索引 writer 以 Windows 后台优先级运行，增量通知始终即时应用。
- 默认搜索在已覆盖目录内自动使用持久索引，覆盖不足自动回退实时扫描；候选/可见页按父目录批量身份核验，2 字符查询使用扩展 2-gram 倒排。
- 按需自动根 + LRU：最多 8 个机会根、64 个总根，保存视图根固定不被淘汰；驱动器根、临时目录和系统目录不会自动索引。
- 点击顶栏可收起路径下拉与搜索弹层，同时保留搜索框和路径下拉按钮自身的点击行为。
- 指标来自单机 release 基准，首次构建与索引体积（2 万文件约 40MB，10 万文件约 205MB）仍受文件规模影响；完整证据与限制见 docs/index-maintenance.md、docs/search-auto-index.md。
