# SIM-963 文件类型图标证据

OpenPencil v14 矢量探索保留原 101 页并增加 5 页，v15 采用用户要求的 image_gen 原始 PNG，再增加 6 页，共 112 页。两版冷重开、图层数量和像素容差检查通过；原始生图和提示词在项目资产目录。

本机原生可见窗口已显示内置生图文件类型图标；真实 `Backleaf.exe` 显示自带叶片图标，普通文本内容的 `无图标.exe` 回退默认应用图标。带 `.png` 后缀的目录显示文件夹。分类与 Windows 图标透明资源测试、搜索目录类型分页验证在内，36 项 Release 测试通过。

本地 EXE 构建、原生截图/辅助功能树、性能报告、staging 与 CI 发布映射分别放在 `raw`，不同编译阶段及机器的 EXE 哈希分开记录。具体交付版本与剩余验证以发布记录为准。

最初素材存在透明白边和光学尺寸偏小，产品已指出；旧截图仅作诊断。v15 修订按实际轮廓扩大到约 40 px，追加圆润文件夹与侧栏共享图案，并在运行资源导出时清理透明边缘。最终原生验证和发布哈希另行记录，不能把初始诊断 EXE 当作最终交付。
