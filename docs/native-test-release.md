Backleaf 0.1.0-preview.15 · Windows x64 测试版

新增16项生产视图GPUI无头交互回归：重命名失焦/错误恢复/已有目标/大小写/Escape/切换右键、路径失败与修正、中文搜索/250ms防抖、独立菜单焦点与生命周期、10万项框选滚动/松手/取消。继续保留81项逻辑、文件操作和原生COM协议测试，合计97项，发布门禁分别记录两层结果。

修复内联重命名遇到同名目标时进入Shell冲突等待的问题：后台核验后返回错误提示、保留草稿并恢复输入焦点，不覆盖目标；仅修改大小写继续支持。无头窗口共用生产Root/TextInput/MenuPopup及工作线程，只有HWND/显示器边界适配，不启动第三方扩展发现或系统会话监听。

PR和staging/main相关推送自动执行只读无头门禁，发包再执行相同门禁并检查源码与报告，包内headless.json保留用例、退出码和日志摘要。文字采用TestPlatform合成度量，提示验证为实际绘制浮层几何与文本/焦点状态；不等于像素、真实字体、UIA/NVDA或原生IME/OLE手势通过。仅这些系统集成、原生窗口和真实性能继续按变化进行实机检查。v38/233页设计不变，本版证据见docs/evidence/preview-15。

以下功能和已测边界沿用preview.14，其实机截图/性能不冒充本版相同字节构建。

右键菜单现在使用独立的owned无边框GPUI窗口，文件、路径和侧栏入口共用自绘样式。第三方扩展只提供条目与命令，支持动态子菜单、禁用/勾选、键盘导航和焦点返回。菜单受屏幕工作区约束，不再被文件容器裁切。

原生OLE加入真实文件的跨窗口/外部传输：冻结选区、后台清单、Ctrl复制/Shift移动、身份与目录环检查；侧栏拖入保留插入位置。CF_HDROP采用完整UTF16及256MiB预算，不截断选择；虚拟文件内容和创建链接暂不支持。

原有81项Release测试包括真实Shell数据对象导入、原生IDropTarget同步/异步协商、实际IFileOperation移动和避免源文件二次删除。233页OpenPencil v38设计冷重开通过。

实机已验证独立自绘扩展菜单、动态子菜单、Esc焦点/选区返回、真实同窗OLE移动及项数/字节进度；7-Zip“测试压缩包”单选1文件/30字节、多选2文件/60字节均未发现错误。跨窗口/Explorer鼠标手势的自动回归受窗口工具终点边界限制，未标为实机通过；混合DPI/拔屏、NVDA和长期压力仍待验证。

此前preview.13的搜索、FileView、索引、归档、恢复、多窗口及海量渲染记录继续保留在仓库；不把旧EXE证据当成本版相同字节的实测。新版性能和staging记录见docs/evidence/preview-14。
