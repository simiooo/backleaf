Backleaf 0.1.0-preview.28 · Windows x64 测试版

拖放与删除刷新修复：应用内完成的删除/移动/重命名等操作不再等待 450ms 防抖，下一帧即重建快照；已移除文件在快照提交前保留淡化内容，不再留下整行空白。外部 OLE 拖放在目录刷新期间不再被判为不可放置，删除文件后连续从 Explorer 拖入可正常接收；随后仍按捕获身份校验目标。证据见 docs/evidence/preview-28。

失败任务重试：任务结束且存在已确认失败项时，任务详情头显示“重试”。只重放状态为失败的顶层项目，成功、未确认、取消、未处理及部分完成目录不重放；重试任务沿用原操作、目标与捕获身份，同一任务只重试一次。真实窗口以锁定文件制造部分失败，释放锁后点击“重试”只复制失败项目，目标无重复且源文件完整；证据见 docs/evidence/sim-954。

Explorer 文件剪贴板互操作实机通过：Backleaf 多文件复制、剪切到 Explorer 粘贴（含非ASCII名称），以及 Explorer 复制文件到 Backleaf 粘贴，均核对实际文件内容；外部剪贴板变化会清除剪切标记。完整记录见 docs/evidence/sim-954。
