Backleaf 0.1.0-preview.13 · Windows x64 测试版

本批次加入路径编辑与磁盘入口、无输入焦点时键入定位、外部文件变更自动刷新、内部拖动与侧栏固定/重排、保存 FileView、本地元数据索引、压缩解压、原生第三方菜单、路径/搜索恢复和独立窗口。文件主区使用16px圆角与极轻浮层。

本轮修复：Tab/Shift+Tab输入遍历及失焦保存、错误草稿与焦点恢复、可访问Alert、文件名/菜单/任务按钮的轻浮层焦点、原生Shell路径与CRLF兼容。侧栏焦点也可键入定位，命中后Enter打开；所有编辑输入保持保护。

76项Release测试及严格Clippy/fmt通过。实机验证中文搜索、FileView失焦保存、重命名中右键、拖动移动/固定/重排、外部CRUD刷新、跨窗口剪切粘贴、ZIP往返及实际进度、正常/强杀恢复、失效路径恢复、长文件名省略/文字tooltip/完整详情和1/2/5/10窗口。221页可编辑OpenPencil v36设计冷重开通过。

最终本机EXE的真实GPUI复测：10万项场景CPU P95 4.42ms；1000万项+8个流光为5.503ms、帧回调P95 15.749ms、峰值工作集82.04MiB，6,999,826项选区身份通过。1120×720逻辑尺寸、125%缩放、Ryzen 7 8745H。数据为生成元数据和窗口内测试控制器；不代表GPU呈现延迟、磁盘吞吐或真实千万文件的磁盘操作。

混合DPI/拔屏、NVDA完整朗读、长期压力及全部第三方扩展命令尚未验证。拖放目前限同窗，不支持外部/跨窗OLE；归档不支持密码/分卷/链接；索引仅为本地元数据。详细操作和界限见包内README。
