Backleaf 0.1.0-preview.16 · Windows x64 测试版

本版修复菜单稳定性：根菜单保留固定“应用操作”入口，异步发现扩展不再改变根菜单高度；各级子菜单使用独立owned GPUI窗口，就绪后以正确尺寸出现。打开/关闭子菜单不调整父菜单尺寸，屏幕边缘仅翻转或限制新子窗。Render不再反复调用SetWindowPos。

20项生产GPUI无头交互回归覆盖原有输入/重命名/搜索/框选场景，以及异步扩展、长子菜单、父窗/祖先位置和尺寸稳定、动态加载、迟到消息、底部翻转、家族焦点和返回owner的命令。另有82项逻辑/文件/COM/隐藏Win32测试（合计102项），包含真实owner/NOACTIVATE样式和父窗边界验证。

可编辑OpenPencil v39共237页，保留此前233页，新增4个稳定菜单状态，独立进程冷重开及图像对照通过。字体、间距、圆角与轻浮层沿用现有基线。

ZIP直接携带经过微软签名、架构和摘要验证的x64 VC++ app-local运行库及来源声明；一行安装仍可补齐/核验同一支持包，不要求管理员、开发工具或手动配置环境变量。运行库和7-Zip DLL保留在应用目录，安装不写系统目录或全局PATH。

文件区CRUD刷新抖动（SIM-1003）以及分区容量、移动介质及时更新、选中文件大小与重复字母循环（SIM-1000）仍在后续单元，本版不声称已修复。搜索已具备持久化增量索引，跨查询结果缓存仍未实现，见docs/search-index-status.md。

此前已实施的路径/分区导航、快捷访问与FileView、元数据索引、归档、恢复、多窗口、海量虚拟渲染、原生OLE及自绘第三方Shell命令保留。第三方发现/调用在隔离宿主中执行，所有程序扩展的兼容性不作通用承诺；owner-draw无文字条目明确不可用，选区预算2048项/512KiB。

无头使用生产Root、TextInput和菜单视图，替换TestPlatform HWND/显示器边界；字体为合成度量。隐藏Win32测试不等于可见DComp/GPU像素、混合DPI、NVDA、原生IME/Explorer完整拖放手势或长期压力通过。相关可见窗口检查保留在最终统一回归，证据按具体EXE区分。
