Backleaf 0.1.0-preview.14 · Windows x64 测试版

右键菜单现在使用独立的owned无边框GPUI窗口，文件、路径和侧栏入口共用自绘样式。第三方扩展只提供条目与命令，支持动态子菜单、禁用/勾选、键盘导航和焦点返回。菜单受屏幕工作区约束，不再被文件容器裁切。

原生OLE加入真实文件的跨窗口/外部传输：冻结选区、后台清单、Ctrl复制/Shift移动、身份与目录环检查；侧栏拖入保留插入位置。CF_HDROP采用完整UTF16及256MiB预算，不截断选择；虚拟文件内容和创建链接暂不支持。

81项Release测试通过，包括真实Shell数据对象导入、原生IDropTarget同步/异步协商、实际IFileOperation移动和避免源文件二次删除。严格Clippy与fmt通过；233页OpenPencil v38设计冷重开通过。

实机已验证独立自绘扩展菜单、动态子菜单、Esc焦点/选区返回、真实同窗OLE移动及项数/字节进度；7-Zip“测试压缩包”单选1文件/30字节、多选2文件/60字节均未发现错误。跨窗口/Explorer鼠标手势的自动回归受窗口工具终点边界限制，未标为实机通过；混合DPI/拔屏、NVDA和长期压力仍待验证。

此前preview.13的搜索、FileView、索引、归档、恢复、多窗口及海量渲染记录继续保留在仓库；不把旧EXE证据当成本版相同字节的实测。新版性能和staging记录见docs/evidence/preview-14。

解压整个ZIP，运行Backleaf.exe。包内含Logo、v38可编辑设计、许可证、7-Zip动态库及对应完整源包；摘要见SHA256SUMS.txt。所有第三方扩展的兼容性不作通用承诺，owner-draw无文字条目明确不可用；选区预算2048项/512KiB。
