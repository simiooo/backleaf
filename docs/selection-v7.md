# v7：文件选择与框选草稿（已被用户要求重做颜色系统）

2026-11-04 最新反馈否定本稿的图标底板与名称强调色组合。该配色未验收、未发布。当前先调研 Meta 的语义色、表面层级和交互叠层，再制作统一状态体系；本稿数值不再作为颜色实施依据。框选与键盘行为仍在 SIM-953 中推进。

以下仅保留被拒绝方案的历史说明。当前稿与规则见 [v9](visual-system-v9.md)。v7 可编辑文件为 `design/Backleaf-v7.fig`，原 44 页加历史草稿 45–47 页；`scripts/design/selection-v7.mjs` 可重建并独立重开。

鼠标选择没有整格边框。44 px 图标居中放在 56 px 中性底板内，选中时底板圆角 6 px；名称背景按实际文字布局收缩，左右各 4 px、上下各 2 px、圆角 4 px。激活窗口采用 #0967D2 底与白字；失焦为 #D6DADF 底与深字。键盘焦点只在名称周围提供独立可见轮廓。单元保持 100 px，高度由图标槽 56、间距 4、名称槽 36 和上下各 2 px 组成；网格行步长仍为 116 px，主要容器上下 16 / 左右 12 px。

空白处按下左键并拖动形成半透明选择框，超过拖动阈值才进入框选；单击空白清除选择。Ctrl/Shift 框选追加，普通框选替换。Esc 取消当前框选并恢复起始选区。靠近视口上下边缘自动滚动，释放鼠标或窗口失焦立即停止。选区覆盖的行列按整数全局行与局部滚动偏移计算，不能构建全部文件节点。

键盘保留方向键、Shift 延伸、Home/End、PageUp/PageDown、Ctrl+A；Ctrl+方向键只移动焦点，空格切换焦点项，Shift+空格延伸。Ctrl+Space 是 Windows 中文 IME 快捷键，不占用。鼠标与键盘输入切换时分别呈现焦点状态。右键菜单与 F2、复制/剪切/粘贴、删除、新建文件夹等真实文件命令是下一独立单元，不把已有详情弹层称为右键菜单。

框选预览只计算可见项命中；提交的复杂选区用压缩 bitmap 在单一后台工作线程生成，合并重复请求、取消旧代次。全选及少量排除保持稀疏反向表示，不能为千万项创建千万个对象；输入及 UI 线程不枚举整份选区。选择计数必须对应当前快照；计算未完成时提供简短选择中状态，不能显示不一致的精确数字。

预定验收：与独立逐项真值比较矩形范围、尾部不满行、追加/取消；千万项全选/排除保持小于 8 KiB 的选区序列化表示；深处小步滚动和连续边缘滚动无 f32 跳变；静止/最小化不持续框选时钟；维持默认持续滚动场景 CPU P95 ≤ 8.33 ms、回调间隔 P95 ≤ 20 ms 和峰值工作集 ≤ 384 MiB。安装版检查鼠标、键盘、失焦及完整文字，部署并发布 staging 后交产品验收。

调研依据：Apple 官方描述图标视图附近起拖进行多选、追加与取消单项，Windows 平台键盘习惯保留。视觉数值为本次设计选择，未声称与某一 macOS 版本逐像素相同。[Apple 选择项目](https://support.apple.com/en-sg/guide/mac-help/mchlp1378/27/mac/27)、[Windows 常用快捷键](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec)。
