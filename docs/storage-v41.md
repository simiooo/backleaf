# SIM-1000 · 存储与选择

OpenPencil v41保留241页，增加六个状态至247页。普通导航行32px，分区行始终60px；标题、容量文字和细使用率条预留固定空间，异步结果和未知容量不改变行高。所有行间隔4px，滚动条按实际行高之和计算，继续只在溢出且鼠标位于侧栏时出现。

分区展示物理总容量和物理剩余量，使用率条反映物理已用比例。tooltip及可访问名称同时提供总量、已用、剩余和当前用户可用量。采用GetDiskSpaceInformationW的Actual与Caller字段区分配额，64位乘法检查溢出，读取失败显示未知，绝不填0。容量单位明确为KiB/MiB/GiB。参考[微软容量结构说明](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/ns-fileapi-disk_space_information)。

CM_Register_Notification注册卷接口的PnP通知；回调只更新代号并唤醒发现线程，不访问磁盘或UI。GetLogicalDrives独立更新盘符，通知后短时250ms重试等待盘符落地，2秒轮询补偿遗漏。两个固定探测线程读取标签和容量，每个盘符最多一个排队与一个在途请求；失联网络盘不占用本地探测槽。新设备代号清除上一介质的数据，迟到结果无法复活已移除磁盘。卸载注册时等待回调退出，注册失败仍有轮询。参考[微软注册与回调约束](https://learn.microsoft.com/en-us/windows/win32/api/cfgmgr32/nf-cfgmgr32-cm_register_notification)。

选择浮层保持28px，不占文件网格布局。显示项数和文件逻辑字节总量；文件夹只参与项数，绝不递归；文件夹单独选中时不显示误导的0B。零字节文件显示0B，未知文件大小保持未知。汇总使用不可变选择位图和快照，后台只保留最新请求，用u128累加，稀疏选择点查、密集选择流式读取，不把全部名称带到UI线程。

单字母重复输入循环匹配并回绕，连续不同字符组成前缀；相同字母作为多字母前缀的一部分时正常累加。快速输入即使合并请求，也按总重复次数前进。第一次重复在后台建立带主键的临时命中表，后续循环使用游标，避免每次重排全部匹配文件；输入框、IME候选和其他编辑状态继续优先处理文字。

无头覆盖字母循环/快速合并/编辑输入保护、文件字节/空文件/非递归文件夹、容量更新前后滚动几何和迟到事件。原生隐藏检查可验证容量API及PnP注册/回调；实际物理插拔、驱动阻塞与可见渲染必须单独实机验证，不由模拟回调推断通过。
