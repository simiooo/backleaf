# 拾径设计契约 · v5 · 2026-11-03

SIM-921 遵循 SIM-934；设计先于开发。本稿待产品验收，当前没有可安装的 GPUI 应用或应用 staging。

## 布局与密度

中性、平面布局；普通文件不套卡片。选中只给文件名区域浅灰底，图标与名称在网格内居中。详情、菜单、任务文本在各自容器中左对齐。减少重复说明，保留必要标签和短错误。

| 元素 | 逻辑像素 |
| --- | ---: |
| 自定义窗口栏 | 高 40 |
| 常用图标 / 鼠标控件 | 16 / 28 |
| Windows 标题按钮 | 46 × 40 |
| 内容区内边距 | 8 |
| 网格列间距 / 行间距 | 6 / 12 |
| 文件图标槽 / 图标至名称 | 44 / 4 |
| 文件单元高度 | 88 |
| 菜单行 / 外边距 / 行内水平边距 | 26 / 2 / 8 |
| 对话框内边距 / 操作区前间距 | 8 / 10 |
| 操作面板外边距 / 行内水平边距 | 6 / 2 |
| 弹层 / 按钮 / 选中区域圆角 | 6 / 4 / 2 |

语义间距采用 2、4、6、8、10 px。每段留白只有一个负责的容器，避免父 padding 与子 gap 重复累计。网格行距 12 px 保留两行名称和独立命中区。数字是依据用户极度收缩要求作出的本轮设计选择，不是用户指定的固定数字。

鼠标布局紧凑；触控输入将控件和菜单行适配至至少 44 px 并重新排版，不重叠扩大相邻命中区域。键盘焦点独立可见，不能通过低对比或过小字号继续收缩。

白色内容、近白窗口栏、灰色文字分隔线；文件夹采用低饱和蓝灰图形。主要文字 #292E33、次要文字 #676D73、错误 #A62D29。Noto Sans SC，正文和文件名 12 px、状态 11 px、10 px 仅次要计数。分发字体须附 OFL；GPUI 实际字体效果待验证。

## 窗口与导航

Home 为真实 Windows 用户目录；默认网格。没有设备入口、额外工具栏、标签页、双栏或命名分组。返回、上一级、路径、唯一快捷访问和搜索整合到同一个 40 px 窗口栏。

空白区返回 HTCAPTION，控件和路径为 HTCLIENT；平台按钮保留 HTMINBUTTON、HTMAXBUTTON、HTCLOSE。保留 Alt+Space、双击最大化/恢复、调整大小与 Snap Layouts。560 px 窄窗保留必要控件及至少 32 px 空白拖动区。命中、DPI、IME、无障碍属于 SIM-935 实测范围。

恢复窗口圆角由 DWM 处理，设计稿 8 px 为视觉参考；最大化、贴靠与旧系统跟随 Windows 行为。保留正常可调整窗口样式，不用顶层逐像素透明或窗口区域模拟圆角。所有图标控件有 tooltip、可访问名称、键盘操作及焦点。有任务或需处理结果时才显示任务入口。

## 选择与操作矩阵

单击选择，双击/Enter 打开；Ctrl 切换、Shift 延伸、Ctrl+A 全选、Esc 清除选择或关闭临时界面。方向键按网格移动焦点并滚入可见区。右键已选文件保留多选，右键未选文件先更改选择。Shift+F10 打开菜单。

| 选择 | 动作 |
| --- | --- |
| 无 | 新建文件夹；剪贴板有文件时粘贴 |
| 单文件 | 打开、复制、剪切、粘贴、移至回收站、其他应用打开、重命名、详情 |
| 单目录 | 打开、复制、剪切、粘贴、移至回收站、重命名、详情 |
| 多项 | 复制、剪切、粘贴、移至回收站、汇总详情；显式打开目录时使用独立窗口 |

不默认加入压缩、永久删除、批量重命名。菜单按选择类型实例化，禁用原因通过短 tooltip 解释；稿中的多选菜单不代表单文件菜单。

## 文件操作过程

一个共享平面面板承载多个任务，每行有独立的数量、实际进度、取消与结果。标题及箭头展开逐文件结果；长列表滚动，不逐文件弹卡片或通知。独立对象才可并行，同对象、父子路径、同名目标协调排队。

总量未知用准备/活动指示，不编造百分比。有真实字节回调时才提供字节进度；Shell 工作量估计点不当作字节、速度或项目数，并独立报告实际完成项数。取消先显示正在取消，等待后端停止；已完成项保留，未处理与失败项分开报告。发出取消不代表回滚。

删除默认回收站：必要时短确认，随后准备、逐项回收、完成/取消/部分失败。成功项从源目录移除；回收站不可用则停止，不转为永久删除。只有系统真实支持并保留撤销信息时才提供撤销。

重命名在原网格行内编辑，预选主文件名、保留扩展名。IME 组合期间 Enter 不提交。冲突、无效名和权限错误保留输入，短错误提示锚定在编辑框下方，使用行间的预留空间，不改变虚拟网格的固定行高。提交时等待且不重复提交，完成或取消后焦点跟随同一文件身份。

复制不改变源外观；目标未完成项有处理中标记。剪切源图标淡化并附剪刀标记，名称仍清楚。粘贴按项成功清除剪切状态，未移动项保留；外部剪贴板变化或 Esc 取消剪切同步清除。跨卷移动按实际复制与删除阶段呈现。

重名冲突可替换、跳过、取消，并明确应用到其余冲突的范围。只重试失败项，不重放成功项。权限、空间、源/目标消失、回收不可用和部分完成需具体到文件与下一步。可访问状态区域报告选择数、任务进展和失败，避免逐字节播报。

## 搜索、快捷访问、恢复

文件名搜索默认当前目录含子目录，全盘范围显式切换。实际索引覆盖、扫描与不可用根目录须可见，类型/日期过滤渐进呈现。此稿不代表内容搜索已实现。

星标只打开一个有序快捷访问列表，包含目录或保存搜索，以图标区分，不新增分组。保存查询、范围、过滤、排序，打开时重跑；编辑列表不改变文件，跨窗口共享编辑检查修订版本。

各窗口独立持有路径、查询、范围、过滤、排序、选择、滚动、焦点和尺寸；共享索引、快捷访问与操作协调。查询代次和窗口身份拒绝过期结果。

关闭多个窗口之一时从恢复集合移除；关闭最后一个保留其位置/搜索；显式退出保留仍打开窗口；崩溃恢复最后提交状态。不可用路径保留并提供重试和 Home。恢复条件而非缓存结果，重新计算相对日期；绝不重放文件操作。隐私窗口不持久化，也不擦除其他窗口状态。以上为待 staging 实测的设计决策。

## 动效与验证

导航整体淡入 90 ms，弹层 120 ms。选择、输入、安全反馈即时，可中断，不对大量文件错峰动画。减少动态效果时直接切换。高对比度用系统色并保留边框、形状和焦点指示。

当前主稿 design/Backleaf.fig，38 页，对应 design/v5。布局源、变量和重建脚本入库。spacing-audit.json 检查实际排版的父子溢出、文字高度、图标至名称距离、居中与拖动空间；cold-reopen-verification.json 由独立进程重开文件并重渲染比较。设计验证不能替代真实 Windows 操作、键盘、屏幕阅读器、触控与性能验收。

大规模处理以 [性能与 UI 契约](bulk-performance.md) 为补充：虚拟化、分页、磁盘清单、有界并发/背压、10Hz进度合并、批量失败及系统剪贴板成本。初始预算须经真实 Windows 应用验证。
