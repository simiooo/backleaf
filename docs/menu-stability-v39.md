# SIM-1001 · 菜单窗口稳定性

v39/237页先于实现，以OpenPencil原生场景图、变量、自动布局和.fig读写生成，独立进程冷重开和截图对照通过。保留此前233页，新增加载、应用菜单、动态子菜单和底部翻转4个状态，前三个状态父菜单均为同一320/180位置及260×256容器。

根菜单从第一帧保留“应用操作”入口，后台Shell发现只改变其可用状态；所有注册命令仍由Backleaf绘制，经此入口进入。每一级使用独立的owned GPUI窗口，窗口的尺寸与位置在创建时确定，父菜单不随其他列的内容变化而移动/改变高度；原生Render不再触发SetWindowPos。动态子菜单等待条目或明确错误就绪后再出现，避免先显示一行加载内容再撑高窗口。长菜单在既定高度内滚动。

子窗采用非激活工具窗，根菜单保留键盘焦点；任意菜单层级的前台切换均按家族整体判断，移动到子窗不关闭父窗，切换到应用外或owner则关闭整组。左/右键跨层，Esc关闭，F2等命令交回原窗口；owner关闭和迟到的Shell响应不能复活已关闭菜单。屏幕边缘只调整新子窗的翻转和高度，不挪动已有菜单。

新增4项生产GPUI无头回归覆盖异步50条应用操作、30条动态子项、父窗/祖先位置尺寸恒定、加载中不创建占位浮窗、迟到响应、底部翻转和家族焦点/退出。另有真实隐藏Win32窗口测试验证owner、NOACTIVATE、非可见性和父窗边界。这些不证明GPU像素、混合DPI或NVDA已验证；可见窗口检查保留在最终统一回归。
