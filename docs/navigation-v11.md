# 原生导航修订 · v11

2026-11-04 用户确认左侧放常用导航，右侧保留可关闭的详情；这覆盖 v6「无侧栏」和将快捷访问只放在标题栏星标中的位置决定。仍只有一个快捷访问集合，目标模型沿用 SIM-920 的目录与保存搜索。

OpenPencil [v11](../design/Backleaf-v11.fig) 保留 v10 的 70 页，新增 14 页；已保存、独立冷打开并逐页重渲染比对。71–80 页覆盖左右布局、hover/单击/编辑、悬浮计数、文件菜单、显式详情、窄窗、空目录和明暗主题，81–84 页补面包屑折叠、根目录和键盘状态。

顶部按 [Ant Design Breadcrumb](https://ant.design/components/breadcrumb/) 的层级返回及下拉组合，以及 [shadcn Breadcrumb](https://ui.shadcn.com/docs/components/base/breadcrumb) 的 Link / Separator / Page / Ellipsis 结构实现。祖先是可点击链接，当前目录用主要文字颜色呈现而不重复跳转；省略菜单保留上级入口，右侧下拉浏览当前层级。双击当前目录文字或路径空白处进入原生编辑，祖先链接单击立即导航。Ctrl+L / Alt+D 同样编辑。

路径 hover 延迟 180 ms 展开浮层，移入浮层后保持可操作；离开后延迟 260 ms 关闭，单击可固定，Esc/外部点击关闭。键盘支持上下、Home/End、Enter、Tab。长路径按实际字体测量折叠，完整路径保留在 tooltip、辅助技术值及编辑框内，不按字节截断文件名。读取目录在单独的 latest-only 工作线程执行，浮层最多 80 个子目录及 256 KiB 路径预算。

侧栏宽 184 px、横向内边距 8 px、纵向 16 px、行高 32 px、行间 4 px、行圆角 8 px。目录位置来自 Windows Known Folders，兼容重定向。当前接通真实常用目录；设计中的「本周文档」是保存视图目标示例，只有搜索后端完成才显示真实入口，不伪造结果。动态保存搜索/分组、索引与恢复分别继续 SIM-920 / SIM-922 / SIM-937。

底部仅有选中项时显示内容宽度悬浮计数，横向内边距 12 px、纵向 16 px、圆角 12 px，使用较菜单更轻的阴影，不预留 footer 高度。文件格的图标与名称仍居中。窄窗显式详情以右侧覆盖层显示，不将网格压到一个文件格以下。

文件与空白处右键使用 v10 上下文菜单；右键已选文件保留多选，未选文件先选中。详情由显式菜单动作或 Alt+Enter 打开。文件命令与快捷键共用分发，输入框获得焦点时处理文字，避免 Delete/Ctrl+X 误操作文件。

原生编辑实现 UTF-16 选择和组合文本、水平滚动、输入上限，以及辅助技术 `SetValue`。实机发现固定 GPUI 的默认辅助动作未处理 `SetValue`，应用已补齐；已复测完整 ASCII/中文路径、无效路径保留输入与原目录、有效中文目录跳转。广泛 IME/NVDA 验收仍归 SIM-935。
