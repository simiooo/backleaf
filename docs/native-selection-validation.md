# SIM-953 · 原生选择与视觉修订

当前版本：`0.1.0-preview.2` 候选。源码、设计与安装产物不能代替实际可见窗口验收。

已完成：

- OpenPencil v9 保留原 v6 的 44 页，增加 8 页状态、浮层和几何修订；两套主题绑定 23 个颜色角色。
- 52 页冷重开、8 页渲染对比、22 组对比度、实际节点几何规则检查通过。原 `Backleaf.fig` SHA256 保持 `505c56ce3c827f128bc75bbc85cf131826acf56a3f5614e67b5b86feb47c3d4a`。
- 真实 GPUI 使用共享颜色和几何规格，内容包裹的选择背景、独立键盘焦点、失焦选中、长名称省略与完整详情。
- 空白处拖动框选、Ctrl/Shift 追加、Esc 恢复、边缘滚动、快捷键选择和分页导航；选择框使用全局 f64 坐标，虚拟列表保持有界 f32 滚动段。
- 千万项全选保留反向稀疏例外；任意矩形选择使用压缩位图，后台工作线程仅保留最新请求，取消结果不得部分提交。UI 只判断可见项与当前矩形的交集。
- `cargo fmt`、release Clippy（拒绝警告）、11 项 release 测试和 release 构建通过；新增依赖许可已纳入 284 个依赖的许可包，没有缺失项。

`--selection-smoke` 仅用于大规模合成数据和报告输出。在真实 GPUI 窗口中，持续拖动至边缘 850 ms，跨过 4096 行虚拟段的重定位边界；随后 Esc 恢复原选区，再验证 Ctrl 追加框选与后台提交。四项检查通过，最终选 7 项且无挂起提交，帧回调最多一个。它调用控制器事件路径，不能当作操作系统鼠标长按证据。

规模模型补充：千万项中按列选择 3,636,364 项，成员与计数验证通过，位图序列化为 1,254,620 字节。本轮 release CPU 模型测试约 62–68 ms；这不是窗口输入延迟或堆内存测量。

本单元尚不包含真实上下文菜单和 Shell 写命令。它们在 SIM-954，之后继续实现 SIM-920 / SIM-922 / SIM-937 的唯一快捷访问、搜索索引和启动恢复。
