# SIM-953 · 原生选择与视觉修订

当前版本：`0.1.0-preview.2`，源版本 `d28e5af81f787fb8257cdce1d484caac667e30c9`。最终安装候选的窗口冒烟与 13 组原生验证已经完成，发布记录见 [部署元数据](evidence/native-selection/staging.json)。产品视觉与完整系统适配仍待验收。

已完成：

- OpenPencil v9 保留原 v6 的 44 页，增加 8 页状态、浮层和几何修订；两套主题绑定 23 个颜色角色。
- 52 页冷重开、8 页渲染对比、22 组对比度、实际节点几何规则检查通过。原 `Backleaf.fig` SHA256 保持 `505c56ce3c827f128bc75bbc85cf131826acf56a3f5614e67b5b86feb47c3d4a`。
- 真实 GPUI 使用共享颜色和几何规格，内容包裹的选择背景、独立键盘焦点、失焦选中、长名称省略与完整详情。
- 空白处拖动框选、Ctrl/Shift 追加、Esc 恢复、边缘滚动、快捷键选择和分页导航；选择框使用全局 f64 坐标，虚拟列表保持有界 f32 滚动段。
- 千万项全选保留反向稀疏例外；任意矩形选择使用压缩位图，后台工作线程仅保留最新请求，取消结果不得部分提交。UI 只判断可见项与当前矩形的交集。
- `cargo fmt`、release Clippy（拒绝警告）、11 项 release 测试和 release 构建通过；新增依赖许可已纳入 284 个依赖的许可包，没有缺失项。

`--selection-smoke` 仅用于大规模合成数据和报告输出。在真实 GPUI 窗口中，验证 Alt+Space 不修改选区，持续拖动至边缘 850 ms，跨过 4096 行虚拟段的重定位边界；随后 Esc 恢复原选区，再验证 Ctrl 追加框选与后台提交。五项检查通过，最终选 7 项且无挂起提交，帧回调最多一个。它调用控制器事件路径，不能当作操作系统鼠标长按证据。

规模模型补充：千万项中按列选择 3,636,364 项，成员与计数验证通过，位图序列化为 1,254,620 字节。最终 release 测试 CPU 计算 59.694 ms；这不是窗口输入延迟或堆内存测量。

常规性能矩阵的 UIA 客户端处于非活动状态，报告保留该字段；窗口冒烟另启用 UIA，不能直接把两种模式的 CPU 数字作速度改进对比。空闲和降低动画没有主动动画请求，预热后样本为零。纯流光回调间隔 P95 为 22–25 ms，没有据此宣称 GPU 呈现达到 60 FPS。

最终实机确认 253 单元名称、472 单元路径的 UIA 正文与复制值相等；千万项全选后排除一个文件得到 9,999,999 项，位图序列化为 30 字节。八条流光最小化 28.501 秒，动画请求数保持 6597，恢复后继续运行，待处理帧回调最多一个。源版本、安装包和原始报告哈希在 [证据清单](evidence/native-selection/manifest.json)，数据及截图在 [证据目录](evidence/native-selection/README.md)。

控制器集成覆盖持续边缘拖动、Esc 和 Ctrl 追加，不代替操作系统层面的所有修饰键鼠标组合。窗口记录保留实际完成范围；NVDA、其他 DPI、外部拖放及 IME 的完整检查继续归 SIM-935。

本单元尚不包含真实上下文菜单和 Shell 写命令。它们在 SIM-954，之后继续实现 SIM-920 / SIM-922 / SIM-937 的唯一快捷访问、搜索索引和启动恢复。
