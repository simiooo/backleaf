# Backleaf 圆叶

本次按用户要求将应用logo改为亲切、卡通、圆润和简单的圆叶表情。轮廓更饱满，没有旧版的尖折角与复杂路径切口；文件类型图标保持现有系统。

生成原件为assets/brand/backleaf-logo-v2.png，运行文件为assets/brand/backleaf-logo.png，旧版保留为backleaf-logo-v1.png。Windows图标保留透明度，包含16、20、24、32、40、48、64、128、256px九档；生成记录见assets/brand/generation.md。

先通过OpenPencil独立品牌稿Backleaf-brand-v2.fig核对明暗背景和小尺寸，再导出ICO。三页独立冷重开0像素差。PNG为生成位图，设计稿编辑范围是摆放、尺寸、背景和排版，不是叶子曲线的矢量编辑。应用的v41/247页界面基线保留。
