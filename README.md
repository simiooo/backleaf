# 拾径 / Backleaf

A Windows file manager with a real directory grid, local search and one quick access list.

Design precedes implementation. Open [design/Backleaf.fig](design/Backleaf.fig), the current v5 editable OpenPencil master; its 38 page previews and verification are indexed in [design](design/README.md). Product scope follows Nuto SIM-919 and SIM-934; multi-window behavior follows SIM-938.

Current status: design revision; no runnable application has been delivered. Application delivery will require a private Windows staging prerelease, installation and smoke checks. Product acceptance is tracked separately from engineering checks.

See [design contract](docs/design-contract.md), [research](docs/research.md) and [delivery status](docs/delivery.md).
